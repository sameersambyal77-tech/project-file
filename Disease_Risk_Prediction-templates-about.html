About This Project

MCA (AI & ML) Minor Project — Research-Level Disease Risk Prediction System

Project Abstract

This project presents a Machine Learning-Based Disease Risk Prediction System designed to predict the probability of a patient developing diabetes using multiple supervised machine learning algorithms. The system preprocesses a synthetic healthcare dataset (1,000 patients, 11 clinical features), trains five classifiers — Logistic Regression, Decision Tree, Random Forest, SVM, and KNN — and automatically deploys the best-performing model via a Flask web application.

The platform supports real-time single-patient prediction, batch CSV processing, automated PDF report generation, patient dashboard with prediction history, and an admin analytics panel. Risk stratification (Low / Medium / High) drives a personalised recommendation engine that delivers evidence-based health guidance to end-users.

Objectives

  • Develop an end-to-end ML pipeline for disease risk assessment
  • Compare performance of 5 ML classification algorithms
  • Implement a complete data preprocessing pipeline
  • Deploy the best model via a production-ready Flask application
  • Build a patient-facing dashboard with prediction history
  • Generate downloadable PDF health reports
  • Support batch prediction via CSV file upload
  • Provide personalised health recommendations by risk level

Key Results

  • Random Forest achieved highest accuracy (~87-92%)
  • All 5 models evaluated with 7 metrics each
  • 1,000 patient records processed successfully
  • Sub-millisecond inference time per prediction
  • Professional PDF reports generated on demand
  • Multi-user support with role-based access control
