# Sorting-Based Projects 🎯

Two comprehensive Python projects demonstrating sorting algorithms with visualization and practical applications.

## Projects

### 1. 🎨 Sorting Visualizer (`sorting_visualizer.py`)
Beautiful GUI application that visualizes 5 sorting algorithms in real-time with bars, colors, and statistics.

**Algorithms:** Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort

**Features:**
- Real-time visualization with color-coded animations
- Adjustable speed and array size
- Live statistics (comparisons, swaps, time)
- Time complexity information for each algorithm

**Run:** `python sorting_visualizer.py`

![Features: Modern UI, Speed Control, Size Control, Algorithm Selection]

---

### 2. 🏆 Student Ranker (`student_ranker.py`)
Console application that ranks students by marks using sorting algorithms with detailed statistics.

**Algorithms:** Insertion Sort, Selection Sort, Bubble Sort

**Features:**
- Add students and rank them by marks
- Step-by-step algorithm visualization
- Comparison and swap counting
- Algorithm performance comparison
- Handles tied ranks correctly

**Run:** `python student_ranker.py`
